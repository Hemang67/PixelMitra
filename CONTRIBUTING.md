# Contributing

1. Open an issue describing the proposed change.
2. Make a focused branch.
3. Run `flutter analyze` and `flutter test` from `mobile/`.
4. Add tests for provider routing, credential lifecycle and offline behaviour where applicable.
5. Never commit API keys, signing files, private media or secrets.

Preserve API-only AI processing. Do not add local AI runtimes, model weights or model downloads without an explicit product decision.
